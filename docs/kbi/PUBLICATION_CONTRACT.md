# Drive-first R&D → GitHub stable reference release contract

- **Google Drive is authoritative for manuscripts, governance, source registry, research decisions, and NEXT handoff.**
- **GitHub is authoritative for runnable code, tests, AGENTS.md, checked-in `.kbi` projections, and versioned public release history.**
- Treat both as distinct authority realms. A passing local test does not approve a public GitHub release.
- Before pushing: license audit, secret scan, test logs, artifact hash manifest, human-safe claim boundary, published documentation, no private Drive text in repo, upstream AGPL separation, provider readback.
- Release semantics: `v0.4.0` is a tested **reference implementation**; do not claim production readiness or genuine OpenViking interoperability without real runtime evidence.
- GitHub repo target: `Ivan-Pasev/fabrica-context-fabric`. Do not invent a repo URL until provider confirms its existence.
- If no GitHub repository-creation action exists, preserve Git-ready ZIP and provide exact new-repo bootstrap procedure; do not claim remote publication.
