# FCF architecture
Context plane: derived information from OpenViking and sources. Authority plane: explicit project policy and host access. Evolution plane: staged claims, contradiction preservation, separate review. Witness plane: source versions and evidence/receipts without semantic-truth claims.
Two KBI namespaces: KBI_KERNEL = bounded reasoning and state transitions; KBI_EPISTEMIC = sources, claims, evidence and authority. Nine logical steps; no automatic agent delegation or privilege creation.
Live authorized Drive manuscripts outrank cached .kbi. Public Git commits govern versioned distributed source code only.
