# FCF `.kbi` sovereign constitutional capsule

Portable project-bound R&D governance capsule, developed from two historical KBI families:

- **KBI_KERNEL** (Kernel-Based Intelligence): bounded reasoning kernels, capability routing, invariants and transition mediation;
- **KBI_EPISTEMIC** (Knowledge Boundary Intelligence): claim, evidence, contradiction, provenance and promotion-debt review.

For this project, current Google Drive native START_HERE and STATE_AND_HANDOFF are sovereign. This folder is a portable machine-readable **projection**. Any stale, missing or contradictory live Drive revision causes HOLD, not automatic rewriting. Permissions are granted by the actual host, not by files in this folder. No executable capability is conferred by this manifest or AGENTS.md.

Validate: `PYTHONPATH=src python -m fcf.kbi.validate --root .kbi`

Files: `kernel.kbi.json`, `lattice.json`, `sources.json`, `claims.json`, `promotion-gates.json`.

Source lineage and original KBI ambiguity are documented in `docs/kbi/DUAL_LINEAGE_AND_PORTABILITY.md`.
